Working Principle

1

双轴反向剪切

两组刀轴（主动轴+从动轴）以不同转速反向旋转，物料被钩入两组Blade咬合区域。Blade采用爪型/平型/V型多刀刃设计，锋利刃口切入物料并产生剪切力。

2

撕裂与挤压破碎

物料在Blade咬合区受到剪切力的同时，相邻Blade之间的Spacer将物料撕裂并挤压，大块物料被逐步分解为小块。Blade厚度20-100mm可选，越厚的Blade适合越坚韧的物料。

3

Screen控制出料粒度

破碎后的碎片通过底部Screen排出，Screen孔径决定出料尺寸。未达粒度要求的物料在腔内继续被Blade破碎，直至通过Screen。遇超硬物料时Intelligent Overload Protection系统自动反转刀轴，排出异物后恢复正常运转。

Shredding Process
Feed Input → Dual-shaft Counter-rotating Blade Engagement → Shearing/Tearing/Crushing → Screen Size Control Discharge → Auto Reverse for Hard Objects

Product Features

Dual-shaft Differential Counter-rotation

两组刀轴以不同转速反向旋转，Blade咬合效率高，处理能力大。物料被主动钩入咬合区而非被动等待，进料顺畅不堵料。

高铬合金Blade，超长耐磨

Blade采用 Cr12MoV / D2 高铬合金钢，经真空热处理后硬度达 HRC 55-62。同等工况下Blade寿命是普通碳钢的 5 倍以上，大幅降低换刀频率和维护成本。

Multiple Blade Types, Material-matched

提供爪刀、平刀、V型刀三种刀型，针对不同物料特性优化。爪刀抓料能力强适合软质物料，平刀适合中硬度物料，V型刀锋利刃口适合硬质物料。

Intelligent Overload Protection

PLC 实时监测Motor电流，遇超硬异物（如钢筋、铁块）时自动反转刀轴并报警，排出异物后恢复正常运转。有效保护Blade免于崩刃，延长设备寿命。

Flexible Discharge Size Control

Screen孔径 20-200mm 可更换设计，根据出料粒度需求灵活配置。无需更换Blade即可实现不同出料尺寸，一机多用、适应多种工况。

Modular Structure, Easy Maintenance

Blade、Spacer、Screen均为独立模块，单件可单独更换。Blade采用分体式安装设计（无需拆卸整根刀轴即可更换单片Blade），维护效率提升 60%。

Application Fields

废塑料回收

适用于各种废塑料制品（PE/PP/PVC管材、塑料桶、塑料托盘、编织袋、薄膜等）的破碎减容。撕碎后的塑料碎片可直接进入清洗造粒线，为资源回收利用提供前置处理。

废橡胶破碎

处理废旧轮胎、橡胶输送带、胶管、橡胶制品等。双轴剪切式破碎可有效撕断橡胶中的钢丝帘线，分离橡胶与钢丝，为下游磨粉或热裂解工艺提供合适粒度的橡胶颗粒。

废旧金属处理

适用于废钢、废铝型材、废铜线、轻薄料（易拉罐、铁皮桶、彩钢瓦等）的撕碎和减容。废旧金属经撕碎后密度提高 3-5 倍，大幅降低运输和回炉成本。

木材破碎

处理废旧木托盘、建筑废模板、树枝树干、树根、废旧家具等木质废弃物。破碎后的木片可直接用于生物质发电、人造板原料、有机覆盖物等用途。

电子废弃物处理

处理废弃电路板、电器外壳、废旧家电（冰箱、洗衣机、空调等）。Shredder作为电子废弃物拆解线的第一道工序，将整机撕碎为小块后进行后续分选（磁选、涡电流分选等）。

生活垃圾减容

处理城市生活垃圾中的大件废弃物（床垫、沙发、桌椅等），以及餐厨垃圾中的有机物料。撕碎后垃圾体积减小 50-70%，显著降低填埋空间和转运成本。

Selection Advice

  1. 来料特性决定刀型：较软的物料（塑料、橡胶）推荐爪刀或平刀，较硬的物料（金属、木材）推荐 V 型刀或重型平刀，不确定时可提供物料样品由我方工程团队推荐。
  2. Blade直径与进料尺寸匹配：Blade直径决定最大咬合开口尺寸，大块物料需选用大直径Blade（如 2500 型 φ600mm），小块物料可选小直径降低成本。
  3. Blade厚度对应物料韧性：Blade越厚抗冲击能力越强，处理废钢材、厚壁管材建议Blade厚度 ≥60mm。
  4. 功率核算：处理能力与Motor功率成正比，建议按物料硬度、含水率和预期处理量综合核算，预留 20% 功率余量。
  5. Screen孔径 = 最终出料尺寸：出料粒度由底部Screen孔径决定，请明确出料要求以便配置合适Screen。
  6. 现场安装条件确认：大型号（2000/2500）外形尺寸大（长度 6-7.5m），需提前确认厂房高度和吊装条件。
